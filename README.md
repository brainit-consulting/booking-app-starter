# Booking app starter

The starting point for **Agentic Builders: Build Your Own Business App**, a BrainIT Consulting course. You build a
booking app for a made-up mobile dog groomer, Pawsome Mobile Grooming, by asking Claude Code (or Codex) for one small
change at a time. Swap in your own business whenever you like.

## What's in here

| File or folder | What it's for |
|---|---|
| `CLAUDE.md`, `AGENTS.md` | House rules your AI helper reads first (the same text: Claude Code reads one, Codex the other) |
| `docs/spec.md` | What the app should do, in plain words |
| `DESIGN.md` | How it looks: colors, fonts, buttons |
| `course/` | The prompt each lesson asks you to paste |
| `app/` | The app's pages (only a placeholder home page so far) |

## Run it

You need [Node.js](https://nodejs.org) 22 or later. In this folder:

```
npm install
npm run dev
```

Then open http://localhost:3000.

The lessons walk you through every step, including installing what you need.
